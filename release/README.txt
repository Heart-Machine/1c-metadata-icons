1. УСТАНОВКА NODE.JS

Скрипту нужен Node.js 20.15 или новее. Ставить npm-пакеты не нужно.
Проверить, установлен ли Node.js и какой версии:

  node -v

Windows. Установите LTS-версию через winget:

  winget install OpenJS.NodeJS.LTS

Можно и без winget: скачайте установщик LTS-версии с https://nodejs.org/ru/download
и запустите его. После установки откройте новое окно терминала, иначе команда
node не найдётся.

Linux. В пакетах дистрибутивов Node.js часто устаревший, поэтому проще поставить
его через nvm:

  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash

Затем откройте новое окно терминала и выполните:

  nvm install --lts

Если node -v уже показывает 20.15 или новее, ничего ставить не нужно.


2. ВЫГРУЗКА В ПРОЕКТ EDT

Распакуйте архив и откройте терминал в папке 1c-metadata-icons-edt. В Windows
для этого можно ввести cmd в адресной строке Проводника и нажать Enter.

В командах укажите каталог проекта EDT, в котором лежит
src/Configuration/Configuration.mdo, или сам его каталог src.

Посмотреть, что изменится, ничего не записывая:

  node scripts/export-edt.mjs --dry-run "D:\path\to\project"

Выгрузить картинки:

  node scripts/export-edt.mjs "D:\path\to\project"

Выгрузить с префиксом имён, например «Мой_МетаданныеРоль» вместо «МетаданныеРоль»:

  node scripts/export-edt.mjs --prefix Мой_ "D:\path\to\project"

Для каждой иконки скрипт создаёт папку CommonPictures/<имя>/ с файлами .mdo
и Picture.zip и регистрирует картинку в Configuration.mdo. Повторный запуск
обновляет картинки и ничего не дублирует.

Скрипт ничего не меняет и просит задать префикс, если в конфигурации уже есть
общая картинка:
  - с таким же именем, созданная не этим скриптом;
  - с именем, которое отличается только регистром, например «Метаданныероль» вместо «МетаданныеРоль».

После выгрузки обновите проект в EDT (F5) и используйте картинки в коде,
например БиблиотекаКартинок.МетаданныеРоль.

Перед выгрузкой лучше закоммитить проект в git: так изменения будет легко
посмотреть и при необходимости откатить.


3. КОНФИГУРАТОР

Для Конфигуратора на странице релиза есть отдельный файл 1c-metadata-icons.cf:
конфигурация, в которой нет ничего, кроме общих картинок. Объедините её
со своей конфигурацией:

  1. Сохраните свою конфигурацию в файл: «Конфигурация → Сохранить
     конфигурацию в файл», чтобы объединение можно было откатить.
  2. «Конфигурация → Сравнить, объединить с конфигурацией из файла»,
     выберите 1c-metadata-icons.cf. Если Конфигуратор предложит поставить
     конфигурацию на поддержку, откажитесь.
  3. В окне сравнения оставьте флажки только у нужных общих картинок.
     Флажок у корня конфигурации снимите, иначе её имя, версия и режим
     совместимости заменят ваши.
  4. Нажмите «Выполнить» и обновите конфигурацию базы данных.

Файл .cf открывается в платформах 8.3.14 и новее.


4. БЕЗ NODE.JS И .CF

Картинки можно загрузить и вручную: создайте общую картинку в EDT или
Конфигураторе и загрузите в неё нужный архив из папки pictures.
